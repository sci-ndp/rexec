# SciDx Remote Execution

Remote Execution (Rexec) enables code execution from jupyter notebooks or python scripts to remote kubernetes compute resources. It is designed to work with the [NDP Endpoint](https://github.com/sci-ndp/ndp-ep-py).

```sh
pip install ndp_ep[rexec]
```

#### Getting Started
Learn to use NDP Endpoint with Remote Execution, walk through the example [`notebook`](./user/rexec_quickstart.ipynb).
